程序控制结构

顺序、分支和循环决定程序的执行路径。初赛常用它们考察代码阅读、循环次数、边界条件和流程图理解。

顺序 分支 循环

顺序结构

顺序结构按代码从上到下执行。初赛题常把赋值语句、复合赋值和自增自减混在一起，要求准确跟踪变量变化。 

int a = 3, b = 5;
a = a + b;  // a = 8
b = a - b;  // b = 3
a = a - b;  // a = 5
读代码方法：遇到连续赋值时，不要心算跳步。按语句顺序写变量表，执行一行更新一次。

分支结构

if / else

分支结构根据条件真假选择执行路径。注意比较运算符、逻辑运算符以及“悬挂 else”问题。 

if (score >= 90) {
    level = 'A';
} else if (score >= 80) {
    level = 'B';
} else {
    level = 'C';
}

switch

switch 适合多分支离散取值。每个 case 后通常需要 break，否则会继续执行后续分支。 

switch (op) {
case '+': ans = a + b; break;
case '-': ans = a - b; break;
default:  ok = false;
}
常见陷阱：= 是赋值，== 才是相等判断；&& 的优先级高于 ||。

循环结构

结构 适用场景 初赛关注点
for 次数明确 初值、终止条件、步长
while 次数不固定，先判断 是否可能一次也不执行
do while 至少执行一次 循环体后面的分号 
int sum = 0;
for (int i = 1; i <= n; i++) {
    if (i % 2 == 0) continue;
    sum += i;
}

这段代码只累加 1 到 n 中的奇数。遇到 continue 会跳过本轮后续语句，进入下一轮判断。

初赛解题清单

读程序题

  • 先找输入范围和初值。
  • 逐轮记录循环变量、关键变量。
  • 遇到 break / continue 单独标记。

流程图题

  • 菱形框表示条件判断。
  • 箭头方向决定执行顺序。
  • 回到前面步骤通常表示循环。
