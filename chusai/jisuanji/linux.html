Linux文件系统结构

/                # 根目录
├── /bin         # 基本命令二进制文件
├── /usr         # 用户程序和文件
│   └── /usr/bin # 应用程序二进制文件
├── /home        # 用户主目录
│   ├── /home/user1
│   └── /home/user2
├── /tmp         # 临时文件
├── /etc         # 系统配置文件
├── /dev         # 设备文件
└── /proc        # 进程信息

常用命令分类

文件操作命令

ls [选项] [目录]

列出目录内容，常用选项：-l(详细信息)、-a(显示隐藏文件)

cd [目录]

切换当前工作目录，cd ~ 回到主目录，cd .. 回到上级目录

pwd

显示当前工作目录的绝对路径

cp [源文件] [目标文件]

复制文件，-r选项用于复制目录

更多常用命令

mv [源文件] [目标文件]

移动或重命名文件

rm [文件]

删除文件，-r选项删除目录，-f选项强制删除

mkdir [目录名]

创建新目录

rmdir [目录名]

删除空目录

文件内容查看命令

cat [文件]

显示文件全部内容

head [文件]

显示文件前几行，默认10行

tail [文件]

显示文件后几行，默认10行

more [文件]

分页显示文件内容

less [文件]

分页显示文件内容，支持上下滚动

grep [模式] [文件]

在文件中查找匹配模式的行

权限管理基础

Linux文件权限用9个字符表示，分为三组，分别代表所有者、所属组和其他用户的权限： 

# 权限示例
-rwxr-xr-- 1 user group 1234 May 1 10:00 filename

# 权限说明
r: 读权限 (4)
w: 写权限 (2)
x: 执行权限 (1)

# 权限组合
rwx = 4+2+1 = 7
rw- = 4+2 = 6
r-x = 4+1 = 5

chmod [权限] [文件]

修改文件权限，如chmod 755 file表示所有者有读写执行权限，其他用户有读和执行权限

CSP初赛Linux解题技巧

命令记忆技巧

按功能分类记忆

  • 目录操作：cd, ls, pwd, mkdir, rmdir
  • 文件操作：cp, mv, rm, touch
  • 内容查看：cat, head, tail, more, less
  • 权限管理：chmod, chown

通过英文原意记忆

  • ls = list (列出)
  • cd = change directory (改变目录)
  • pwd = print working directory (打印工作目录)
  • cp = copy (复制)
  • mv = move (移动)
  • rm = remove (删除)

常见考点解析

1

命令选项组合

如ls -la表示以详细格式显示所有文件（包括隐藏文件），注意选项可以合并简写。

2

通配符使用

*匹配任意字符序列，?匹配单个字符，如rm *.txt删除所有txt文件，ls file?.cpp匹配file1.cpp、file2.cpp等。

3

管道与重定向

|用于将一个命令的输出作为另一个命令的输入，如ls | grep "txt"；>用于重定向输出到文件，>>用于追加内容。

4

权限计算

记住r=4, w=2, x=1，能快速计算权限值，如rwxr-xr--对应754。

应试策略

  • 优先掌握常用命令的基本用法和常见选项

  • 熟悉相对路径和绝对路径的区别与使用
  • 通过实际操作加深对命令的理解和记忆
  • 注意区分容易混淆的命令，如rm和rmdir，cp和mv

CSP初赛Linux例题解析

例题1：文件权限计算

题目：在Linux系统中，一个文件的权限表示为"-rwxr-xr--"，请问以下说法正确的是：

  1. 文件所有者具有读、写、执行权限
  2. 同组用户具有读、写权限
  3. 其他用户具有读权限
  4. 该文件的权限值为754

解析：

权限字符串"-rwxr-xr--"分为三组：

  • 第一组"rwx"：所有者权限，具有读、写、执行权限（正确，对应选项1）
  • 第二组"r-x"：同组用户权限，具有读和执行权限，没有写权限（选项2错误）
  • 第三组"r--"：其他用户权限，只有读权限（正确，对应选项3）
  • 权限值计算：rwx=7，r-x=5，r--=4，总权限值为754（正确，对应选项4）

答案：1、3、4正确

例题2：命令功能判断

题目：在Linux系统中，要将当前目录下所有扩展名为".cpp"的文件复制到"/home/user/code"目录下，应该使用哪个命令？

  1. cp *.cpp /home/user/code
  2. copy *.cpp /home/user/code
  3. cp .cpp* /home/user/code
  4. mv *.cpp /home/user/code

解析：

  • 选项1：cp是复制命令，*.cpp匹配所有cpp文件，目标路径正确（正确）
  • 选项2：Linux中没有copy命令，这是Windows系统的命令（错误）
  • 选项3：.cpp*匹配以.cpp开头的文件，而非扩展名为.cpp的文件（错误）
  • 选项4：mv是移动命令，不是复制命令（错误）

答案：1

例题3：目录操作综合

题目：用户当前在目录"/home/user"下，执行以下命令序列后，当前所在目录是什么？

cd code/../test
mkdir ./program
cd program/../../
  1. /home/user
  2. /home
  3. /home/user/test
  4. /home/user/code

解析：

  • 初始目录：/home/user
  • 执行"cd code/../test"：code/..表示回到code的上级目录，即当前目录，再进入test，所以当前目录变为/home/user/test
  • 执行"mkdir ./program"：在当前目录创建program子目录，不改变当前目录
  • 执行"cd program/../../"：进入program目录，再向上两级，即从/home/user/test/program回到/home/user

答案：1

例题4：管道命令应用

题目：在Linux系统中，要在当前目录下的所有".txt"文件中查找包含"algorithm"字符串的行，并显示这些行所在的文件名和行号，应该使用哪个命令？

  1. cat *.txt | grep algorithm
  2. grep -n algorithm *.txt
  3. find *.txt -name algorithm
  4. ls *.txt | grep -n algorithm

解析：

  • 选项1：能找到包含algorithm的行，但不显示文件名和行号（错误）
  • 选项2：grep命令的-n选项显示行号，对多个文件搜索时会显示文件名（正确）
  • 选项3：find命令用于查找文件，不是查找文件内容（错误）
  • 选项4：只在文件名中查找，不是在文件内容中查找（错误）

答案：2
